# CRISP 分析方法論

> 載入時機：進入書籍分析時。
>
> CRISP 是內部推理流程，不是要求報告逐一顯示五個同名章節。依序完成 **Comprehend → Review → Internalize → Synthesize → Practice**，再把結果映射到既有 JSON 欄位。後一階段不能用順暢文字補回前一階段缺少的材料、推論或讀者情境。
>
> 除非使用者明確要求方法說明，Adler、Zettelkasten、Steel-Manning、五階段名稱，以及 schema、契約或模式選擇的內部流程自述都不得出現在使用者可見報告；報告只呈現實際已讀、未讀、可理解且可核對的判斷、依據與限制。TIPS 規則見 SKILL.md。

## 先分類，再決定深度

| 書型 | 代碼 | Review 重點 |
|---|---|---|
| 理論思想 | theory | 論證邏輯、前提假設、可證偽性 |
| 工具技術 | practical | 步驟可行性、適用範圍、與既有方法比較 |
| 商業管理 | business | 案例品質、觀點新穎度、可遷移性 |
| 自我成長 | self_help | 科學性、長期效果證據、責任歸因 |
| 歷史傳記 | narrative | 史料可靠性、選材與敘事偏見 |
| 科普 | pop_science | 是否忠於原始研究、有無過度簡化 |
| 小說／文學 | literature | 敘事、人物、語言、意象、主題與多重詮釋 |

一本書可有主要與次要書型。混合文本把可驗證論證與文學性內容分開處理，再於 Synthesize 合流。

| 模式／lens | 最低完成深度 |
|---|---|
| 完整非虛構 | 五階段；Practice 仍受讀者情境限制 |
| 完整文學 | C、I、S 為主；R 檢查文本依據與其他讀法；P 可不適用 |
| 筆記深化 | 保留讀者原判斷，補 C 的材料界線、R 的挑戰、S 的連結 |
| 快速評估 | C、R 足以回答是否值得讀；I、S、P 有材料才做 |
| 初步評估 | 只處理實際查到的書目、樣章或公開材料；不可冒充全書分析 |
| 部分／失敗提取 | 先縮小要求範圍或降低模式；未讀部分停下 |

### 方法角色

| 方法 | 在 CRISP 中的角色 |
|---|---|
| Adler 分析閱讀 | C 重建整體與細節，R 判斷是否有道理 |
| Steel-Manning | R 忠實處理作者論證的最強版本 |
| Self-Explanation／Feynman | I 以自己的語言回答 What／Why／Connection |
| Zettelkasten | S 建立可回查、可遷移且有機制的知識連結 |
| 應用導向閱讀 | P 將理解轉成有邊界、可回顧的選擇 |
| TIPS | 橫跨各階段的四維觀察，不取代推理或加總成總分 |
| 來源、coverage、attribution | 橫跨各階段且不可妥協的證據約束 |

## 1. Comprehend — 先確定理解的是什麼

### 1.1 分開三種問題

不要把三者揉成一句：

1. **作者問題**：作者試圖回答或呈現什麼？
2. **讀者問題**：使用者希望透過這本書解決、理解或判斷什麼？未知就標未知。
3. **分析問題**：在現有材料與任務範圍內，本次能可靠回答什麼？

先判斷作者處理的是根因、症狀、價值衝突，還是尚未證明存在的問題。若問題本身只是假設，不要直接進入解法評比。

### 1.2 建立 coverage

逐項記錄：

- 要求範圍、實際讀取範圍、未讀與失敗位置。
- 材料類型：全文、指定章節、讀者筆記、樣章、公開書目或其他。
- 可定位方式與來源身分。
- 哪些主張只能做初步判斷，以及缺漏如何影響後續階段。

只有實際讀到的材料算已讀。模型記憶不能補成 coverage。

### 1.3 重建全書骨架

從材料萃取邏輯，不複製目錄：

1. 核心提問。
2. 主論點或主要張力。
3. 論證／敘事結構：線性推演、並列佐證、問題解方、對比辯證，或文學敘事結構。
4. 關鍵概念的因果、從屬、對比與邊界。
5. 章節各自扮演的功能，以及跨章依賴。

用 Adler 前兩問自查：整體在談什麼？作者具體說了什麼？不要在尚未重建作者觀點時直接評論。

### 1.4 Comprehend 完成條件

- 問題、主張、結構與材料界線彼此一致。
- 作者問題、讀者問題、分析問題沒有混淆。
- 重要判斷可回到來源位置。
- 不確定之處已標示，沒有用常識或模型記憶補洞。

若未達成，Review 只能針對已理解的局部範圍。

## 2. Review — 審視最強版本，而非只表態

### 2.1 先忠實重建，再提出影響

每個關鍵論證至少分三層：

1. **作者實際主張**：忠實轉述文本並保留來源。
2. **分析者補強**：補上最合理的前提或論據時，明標為分析者建構，不回寫成作者原意。
3. **評估影響**：說明問題影響哪段推論、結論強度或適用範圍。

Steel-Manning 不是替作者補造證據。批判要分清是針對原論證，還是補強後的最好版本。

### 2.2 挖出前提與邊界

檢查世界觀、讀者、因果、測量與文化假設。接受前提只是論證成立的**必要條件，不是充分條件**；仍需檢查證據、推論與其他解釋。拒絕某個前提也不必然推翻全部結論，要指出實際影響範圍。

為關鍵概念記錄有效條件、失效條件與未知邊界；沒有材料時不硬填。

### 2.3 證據、推論與其他解釋

對重要結論依序辨認：

- **證據**：文本實際提供什麼觀察、研究、案例或史料？
- **推論**：證據如何走到結論，中間缺哪些步驟？
- **外推**：作者是否從少數案例、特定族群或短期結果推到更大範圍？
- **其他解釋**：反向因果、共同原因、選樣、測量或情境差異能否解釋同一現象？
- **共享假設**：看似不同的支持與反對說法，是否其實都依賴同一個未驗證前提？

**證據不足提高不確定性**，不會自動證明主張為假。分辨材料未提供、作者沒有證據、證據衝突與已有反證；四者結論不同。沒有可信依據時降低判斷強度，並指出什麼資訊會改變判斷。

### 2.4 Adler 三類反對

| 類型 | 判斷標準 |
|---|---|
| 知識不足（Uninformed） | 漏掉會改變結論的重要事實 |
| 知識錯誤（Misinformed） | 使用錯誤、失效或誤讀的資訊 |
| 邏輯謬誤（Illogical） | 前提與結論之間有可指出的跳躍 |

自查：能否具體指出問題？有何證據？反對的是論證、適用範圍，還是只是不喜歡結論？

### 2.5 表格與數字

比較性結論先**逐列重算**。至少檢查每列加減關係、分母、單位、期間與例外列。原始數字、算術結果與因果解釋分開；算術一致不等於因果成立。無法讀取圖表或缺必要欄位時，降低結論強度並寫入 coverage。

逐列結果寫成總結、範圍、最小值、最大值或「全部／多數」之前，再從已重算的每列數值做第二次核對；摘要中的百分比不得靠印象改寫，且要保留正確分母。

### 2.6 品質面向

檢查論證完整性、證據品質、內部一致性、範圍適切性、其他解釋與原創性。重要反例和矛盾不因版面或預設項目數被排除。

### 2.7 事實查核與公眾評價

兩者是不同任務：

- **事實查核**：核對可驗證主張、引文、研究或史實；列出查核對象、來源、結果與限制。
- **公眾評價**：整理讀者、評論界或社群如何看待本書；不能用聲量取代真偽。

公眾評價只有使用者明確要求才做。事實查核依任務要求，或在遇到具體且重要的可驗證主張時有限度啟動。只有公開搜尋能力可用時才執行；優先原始研究、出版社、作者原文與負責機構。

### 2.8 文學分支

文學分支檢查敘事視角與結構、人物慾望與變化、語言／意象、主題張力，以及形式如何改變內容。區分文本線索和分析者詮釋；可以保留多個有文本依據的讀法，不急著收斂成單一教訓。

不要強套科學性、工具步驟或「作者說得對不對」。涉及歷史或科學主張時可另做事實查核，但不把虛構敘事當學術論證。

### 2.9 Review 完成條件

- 最強版本、證據、推論與其他解釋已分開。
- 支持與反對都說明依據、邊界和影響。
- 不確定性與可能翻轉判斷的資訊已明示。
- 文學作品使用文本與詮釋標準，而非硬套非虛構評分。

## 3. Internalize — 用自己的語言重建

### 3.1 What / Why / Connection

對核心論點、難段落與前後矛盾處回答：

- **What**：不用原句，我如何清楚說明它？
- **Why**：它為什麼成立，依賴哪些前提與證據？
- **Connection**：它和前文、其他概念或已知讀者情境如何相連？

任一答不出來都代表尚未內化，要回到 Comprehend 或 Review，而非換句話抄摘要。

### 3.2 讀者脈絡與既有筆記

- 有讀者目標、限制、經驗或原筆記時，保留其原判斷和疑問，再說明哪些地方被支持、挑戰或精緻化。
- 沒有讀者脈絡時，只能說「這個觀點可能改變的理解」，不可宣稱讀者已改變、已認同或會受益。
- 分清楚文本「沒有明說」、材料「沒有包含」和目前「尚不知道」。不要把缺席誤判為反證。
- 未讀章節不得以「可能」「也許」等保留語猜測其內容、功能或是否會回答現有問題；只能說尚未確認，以及需要讀取什麼才能判斷。

### 3.3 認知差距

若已知讀者原先理解，描述讀前到讀後可能發生的具體 delta：概念變得更精確、因果模型改變、適用邊界收窄，或原先二分法被拆開。只寫可由材料與讀者脈絡共同支持的差距。

### 3.4 Internalize 完成條件

- 核心內容能以自己的語言解釋，且沒有失真。
- Why 能回到 Review 過的證據與推論。
- 個人化程度不超過已知讀者脈絡。
- 未知、未明說與材料缺失已分開。

## 4. Synthesize — 建立跨章與跨領域結構

### 4.1 跨章合成

整合時回答：

- 哪些章節是同一論證的不同步驟，哪些只是重複案例？
- 哪些概念互相支援、限制或矛盾？
- 支持與反對是否共享同一前提？
- 多項證據是否其實來自同一資料或機制，不能重複計算成獨立支持？
- 全書讀完後，哪個局部判斷需要修正？

Synthesis 不是把多份摘要黏起來。必須說清楚關係如何成立。

### 4.2 Meta Knowledge

保留真正可跨領域遷移的思維模型、邊界條件或認知轉變到 `meta_knowledge[]`。判準是：離開本書主題仍能用來看另一種問題嗎？只在本書題材內有效的不算；沒有合格內容可留空。

### 4.3 Zettelkasten

| 層次 | `type` | 要求 |
|---|---|---|
| 閃念筆記 | `fleeting` | 捕捉閱讀當下的待驗想法 |
| 文獻筆記 | `literature` | 一則一概念、自己的話、可回查出處 |
| 永久筆記 | `permanent` | 完全自己的語言、說明重要性、至少一個有意義連結 |

每個跨書或跨領域連結都要說明**連結機制**（因果、對比、共同前提、方法互補等）與**關鍵差異**。只有主題或書名相近不構成知識連結；說不出機制就不要硬連。

### 4.4 長書分批合併

每批保留來源位置、核心論點、概念定義、反證、矛盾、未解問題與方法。完成後：

1. 合併重複概念，以最完整定義為準。
2. 從要求範圍的整體視角重組論點，不按章節拼接。
3. 補上跨章矛盾與依賴。
4. 只保留可定位且有分析價值的引句。
5. 去除重複、無情境或不可執行的行動。

### 4.5 Synthesize 完成條件

- 跨章關係有來源與連結機制，不是摘要堆疊。
- 相依證據未被重複計算。
- meta knowledge 與永久筆記能說明遷移方式及關鍵差異。
- coverage 不足時沒有生成超出材料的全書結論。

## 5. Practice — 從理解走到可檢驗選擇

### 5.1 分開三件事

對每個候選應用分開寫：

1. **證據**：書中或外部查核實際支持什麼？
2. **適用性**：讀者情境與原情境有哪些相同、不同與未知？
3. **行動**：在目前不確定性下，值得採取哪個可觀察步驟？

證據良好不代表適用，適用也不代表應立即全面採用。

### 5.2 取捨、可逆性與翻轉條件

提出行動前檢查：

- 帶來什麼利益、成本、風險與機會成本？
- 對誰有利，代價由誰承擔？
- 行動是否可逆？能否先做小規模、低成本測試？
- 哪個未知資訊最可能翻轉決定？
- 下一步收集哪項資訊的資訊增益最高？

優先把不確定主張轉成可停止、可回顧的實驗，而不是把閱讀心得變成承諾。

「可逆」「低成本」「低風險」本身也需要情境依據。若不知道撤回時間、殘留影響、受影響者或可承受損失，不得用這些詞替候選行動背書。

### 5.3 行動格式

只有讀者情境足夠時才提出個人化行動承諾。每個承諾需包含：

| 要素 | 要求 |
|---|---|
| 時間／觸發 | 何時或在什麼事件發生時 |
| 對象／情境 | 在哪個工作、關係或決策中 |
| 具體行動 | 可觀察、可判斷是否完成 |
| 回顧條件 | 何時檢視效果，什麼情況停止或調整 |

沒有讀者情境時，只有在材料足以界定適用條件、主要成本與風險時才給明標的候選應用；否則留空。不可虛構承諾。文學閱讀若目標是體驗、詮釋或審美，Practice 可為 `not_applicable` 或不產生 action。

### 5.4 Practice 完成條件

- 證據、適用性與行動沒有混為一談。
- 關鍵 trade-off、可逆性與翻轉條件已說明。
- 行動可觀察、可回顧，且強度與證據相稱。
- 沒有讀者情境時，不冒充個人化建議。

## 映射到既有輸出

五階段只組織內部推理，不新增 schema 欄位：

| 內部階段 | 主要映射 |
|---|---|
| Comprehend | `coverage`、`book`、`summary`、`core_arguments`、`key_concepts` |
| Review | `core_arguments.body`、`critical_perspectives`、TIPS 理由與限制 |
| Internalize | `key_concepts`、`meta_knowledge.delta`、有依據的讀者連結 |
| Synthesize | `meta_knowledge`、`zettelkasten`、跨章論點與概念關係 |
| Practice | `actions`、候選應用與回顧條件 |

同一欄位可承接多個階段的結果。沒有合格內容就使用契約允許的空值、`unknown`、`not_applicable` 或 coverage 限制，不為了版面完整補造資料。
